## 功能性需求（Functional Requirements）

### FR-1 课表查看
- FR-1.1 周视图：以"星期 × 节次"网格展示整周课程
- FR-1.2 日视图：展示单日课程列表
- FR-1.3 学期设置：用户设定学期起始日期（第一周周一），系统据此自动计算"当前是第几周"
- FR-1.4 课程按周次范围显示（如第 1-16 周；支持单双周）

### FR-2 课程管理（增删改）
- FR-2.1 添加课程：课程名、教师、上课地点、星期几、节次范围（如第 1-2 节）、周次范围（如 1-16 周 / 单周 / 双周）、颜色标记
- FR-2.2 编辑课程：修改上述全部字段
- FR-2.3 删除课程：带确认提示
- FR-2.4 节次时间表：可配置每节课的开始/结束时间（提供常见默认模板）

### FR-3 上课提醒
- FR-3.1 课前提醒：在课程开始前 N 分钟提醒（N 可配置，默认 15 分钟）
- FR-3.2 提醒方式：浏览器 Notification API（需用户授权）+ 页面内提示作为降级方案
- FR-3.3 提醒仅在页面打开时生效（纯前端架构的固有限制，需在 UI 中说明）

### FR-4 数据持久化
- FR-4.1 所有数据存于浏览器 localStorage
- FR-4.2 数据导出为 JSON 文件（备份）
- FR-4.3 从 JSON 文件导入数据（恢复/迁移）

## 非功能性需求（Non-Functional Requirements）

- **NFR-1 响应式布局**：手机（≤768px）与桌面浏览器均可用，移动端优先
- **NFR-2 技术栈**：Vue 3（Composition API）+ Vite 构建；不引入后端
- **NFR-3 性能**：纯本地应用，首屏加载 < 2s（常规网络），交互响应即时
- **NFR-4 浏览器兼容**：现代浏览器（Chrome / Edge / Safari / Firefox 最新两个大版本）
- **NFR-5 可用性**：操作简单直观，目标用户为大学生个人使用
- **NFR-6 数据安全**：数据不出本机；localStorage 容量约 5MB，对本场景绰绰有余

## 明确排除（Out of Scope）

- 教务系统对接 / 课程自动导入
- 用户账号、登录、多端同步
- 考试安排 / 作业 DDL 管理（Q2 未选）
- 任何后端服务与数据库

## 关键风险与约束

- 浏览器 Notification API 需要用户授权，且页面关闭后提醒不生效（FR-3.3 已约束）
- localStorage 清除浏览器数据会丢课表 → 以 FR-4.2/4.3 导出/导入缓解
